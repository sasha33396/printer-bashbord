# Printer Dashboard

Система учёта печатающей техники.

## Быстрый старт

### 1. Настройка окружения

```bash
cp .env.example .env
```

Открыть `.env` и заполнить:

| Переменная | Описание |
|---|---|
| `ADMIN_LOGIN` | Логин администратора |
| `ADMIN_PASSWORD` | Пароль администратора |
| `SECRET_KEY` | Случайная строка для подписи JWT (например: `openssl rand -hex 32`) |
| `WSL_IP` | IP-адрес WSL-хоста в локальной сети (заполняется вручную или автоматически через `start.sh`) |

### 2. Запуск

```bash
chmod +x start.sh && ./start.sh
```

Скрипт автоматически определяет WSL IP командой `hostname -I` и передаёт его в сборку фронтенда.

### 3. Открыть в браузере

```
http://<WSL_IP>:3000
```

Работает с любого устройства в локальной сети (ПК, телефон, планшет).

---

## Узнать WSL IP вручную

```bash
hostname -I | awk '{print $1}'
```

## Сервисы

| Сервис | Адрес |
|---|---|
| Фронтенд (nginx) | `http://<WSL_IP>:3000` |
| API (FastAPI) | `http://<WSL_IP>:8000` |
| Документация API | `http://<WSL_IP>:8000/docs` |

## Остановка

```bash
docker-compose down
```

Данные БД сохраняются в Docker volume `db_data` и не удаляются при остановке.
