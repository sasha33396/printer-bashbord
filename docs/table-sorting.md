# Сортировка таблиц

Нажатие на заголовок столбца переключает порядок: по возрастанию, по убыванию,
затем исходный. Стрелка у заголовка показывает выбранное направление.

- Текст сортируется по русскому алфавиту без учёта регистра.
- Числа и номера сравниваются естественно: 2 идёт перед 10; дробные значения
  и отрицательные числа сохраняют числовой порядок.
- Даты сравниваются по времени, включая переходы между месяцами и годами.
- Пустые числовые поля и даты при общей сортировке остаются в конце в обоих направлениях.
- Сортировка применяется вместе с фильтрами ко всем строкам таблицы до разбиения
  на страницы. В «Истории движений» это выполняет сервер для всего журнала.
  Исходный порядок журнала — сначала новые события.

Общие правила реализованы в `FilterableTable` и `utils/tableSorting.js`.
Для сложной ячейки можно задать `sortValue: row => value`, чтобы сортировать
по основному значению без вспомогательных кнопок и подписей. `sortable: false`
отключает сортировку столбца; колонки действий и порядковые номера строк
не сортируются. Явно заданные `sorter` и `defaultSortOrder` сохраняются.

API `/api/history` принимает `sort_by` (`occurred_at`, `category`, `event`,
`entity`, `direction`, `employee_name`, `actor`) и `sort_order` (`ascend`, `descend`).
В SQLite используется сравнение русского текста и числовых частей, независимое
от настроек языка операционной системы. Изменение схемы базы не требуется.
