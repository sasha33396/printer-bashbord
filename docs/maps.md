# Интерактивная карта помещений

Раздел **Карта помещений** содержит здания и планы этажей. План можно начертить
с нуля или использовать готовое изображение как подложку. Рабочие места,
печатающая техника и поштучное оборудование размещаются отметками, связанными
с существующими карточками.

## Создание плана

1. Нажмите «Добавить здание», задайте название, адрес и при необходимости филиал.
2. В блоке «Этажи / планы» нажмите «+». Укажите название и размеры плана в метрах.
   Один план может представлять этаж, отдельное помещение или схему всего здания.
3. Нажмите «Редактировать план».
4. Выберите «Кабинет» и протяните прямоугольник. Название, номер, отдел, цвет и размеры меняются
   в панели «На плане». Сложные контуры можно составить из отдельных стен.
5. Инструментами «Стена» и «Дверь» протяните линии; «Подпись» добавляет текст
   по щелчку на плане. Дверь отображается проёмом с направлением открывания.
6. Нажмите «Сохранить план». Геометрия, отметки и новая подложка сохраняются вместе.

Размеры плана меняются через «Параметры плана». Уменьшение, при котором элементы
оказались бы за границами, блокируется. Редактор использует схематические размеры
в метрах; задание ширины и длины изображения не измеряет помещения автоматически.

## Подложка из изображения

В режиме редактирования нажмите «Загрузить подложку». Поддерживаются JPEG, PNG
и WebP размером до 10 МБ. Подложка занимает прямоугольник плана. Задайте размеры
по реальному зданию; кнопка «Пропорции изображения» подбирает длину по соотношению
сторон картинки при сохранении заданной ширины.

Ползунок регулирует видимость подложки. «Убрать подложку» удаляет её при следующем
сохранении. До сохранения выбор изображения и изменения видны только в редакторе.
PDF нужно предварительно преобразовать в изображение.

## Кабинеты и их содержимое

Кабинет имеет постоянный идентификатор на плане, номер, название, отдел и примечание.
Непустые номера уникальны в пределах этажа. Отдел выбирается из филиала здания.
Щелчок по кабинету открывает состав: рабочие места с сотрудниками, принтеры и
оборудование, в том числе закреплённое за рабочими местами. Повторные ссылки
на один предмет не увеличивают количество оборудования.

Отметки внутри границ автоматически относятся к кабинету. Кабинет также можно
выбрать в свойствах отметки — при необходимости она переместится внутрь него.
Перетаскивание кабинета переносит связанные с ним отметки; заблокированные
элементы остаются на месте. Удаление кабинета сохраняет его отметки на плане.
Привязка кабинета к отделу не меняет филиал и отдел учётных карточек.

## Размещение сотрудников и оборудования

Слева доступны поиск по всем зданиям и этажам и типы **Рабочие места**,
**Сотрудники**, **Печатающая техника**, **Оборудование**, **Кабинеты**.
Поиск учитывает ФИО, номер кабинета, название, отдел и инвентарный номер,
а для рабочих мест и кабинетов — также закреплённое оборудование.
Результаты отсортированы по алфавиту с числовым порядком номеров.

Сотрудники представлены отдельными строками, включая тех, у кого ещё нет рабочего
места; неактивные сотрудники помечены. Нажатие на размещённого сотрудника открывает
нужный этаж и выделяет его текущее рабочее место. В режиме редактирования сотрудник
с назначенным рабочим местом позволяет разместить это место. Отдельная неподвижная
отметка человека не создаётся: смена сотрудника в учёте не оставляет старое ФИО
на карте. Для сотрудника без рабочего места открываются данные и объяснение.

В режиме редактирования выберите объект в списке и нажмите на его место на плане.
Для перемещения включите «Выбор» и перетащите отметку. Точные координаты и поворот
задаются в панели «На плане».

У рабочего места показываются текущий сотрудник и закреплённое оборудование
со ссылками на карточки. Изменения сотрудника и состава оборудования берутся
из учётных данных при открытии или обновлении плана.

У каждой карточки может быть одна собственная отметка во всех зданиях. Если она
уже находится на другом этаже, редактор просит подтвердить перенос. При сохранении
отметка исчезает с прежнего этажа, а версии обоих планов обновляются. Параллельно
открытый старый план не сможет вернуть её обратно устаревшим сохранением.

Оборудование рабочего места можно найти через отметку этого рабочего места без
отдельной отметки каждого монитора или компьютера. Установленный картридж можно
найти через отметку принтера. При необходимости отдельная отметка оборудования
имеет приоритет при поиске.

Здание можно привязать к филиалу. На его планах размещаются объекты этого филиала
и объекты без указанного филиала. Размещение на карте не заменяет складские передачи
или перемещение рабочего места между филиалами. Если филиал объекта впоследствии
изменится, старая отметка помечается предупреждением и требует переноса или снятия.

## Просмотр и управление

- «Полный экран» разворачивает рабочую область поверх приложения. Список и свойства
  сворачиваются отдельно. `Esc` завершает полноэкранный просмотр.
- Слои управляют видимостью рабочих мест, сотрудников, печатающей техники,
  оборудования и подписей на самом плане. Сотрудники отображаются через рабочие места.
  При отдалении подписи сокращаются и скрываются при наложении; при приближении
  или выборе отметки показываются подробности.
- Размеры и площадь кабинетов на плане скрыты по умолчанию, в том числе при
  редактировании. Переключатель «Размеры кабинетов» показывает и скрывает их
  отдельно от подписей, линеек и отступов. Размеры в панели свойств остаются доступны.
- «Подсветка состояний» использует реальные состояния учёта: свободные места зелёные,
  неиспользуемые — серые, техника в ремонте — красная. Архивные отметки и расхождения
  филиала помечаются серым. Легенда объясняет цвета.
- Над планом видны количества кабинетов, рабочих мест, сотрудников, свободных мест
  и принтеров; сканеры не увеличивают счётчик принтеров. Фильтр «Контроль размещения»
  показывает текущий этаж, неразмещённые, архивные/неактивные или сменившие филиал
  объекты. «Обновить карту» заново получает текущие учётные данные.
- Колесо мыши и кнопки «+»/«−» меняют масштаб; «Весь план» возвращает общий вид.
- Средняя кнопка мыши или инструмент «Перемещение вида» двигают видимую область.
- Щелчок выбирает элемент, двойной щелчок по отметке в режиме просмотра открывает
  карточку. На телефоне можно выбрать отметку и нажать «Открыть карточку».
- Синие маркеры по углам и сторонам комнаты или стола меняют размер; `Shift`
  сохраняет пропорции. Маркер конца стены или двери
  меняет конечную точку. Для этого используйте инструмент «Выбор».
- Сетка может отображаться независимо от привязки. Шаг привязки — 0,5 м, 1 м
  или без привязки.
- `Ctrl+Z` отменяет, `Ctrl+Shift+Z` повторяет изменения рисунка и отметок.
- `Delete` снимает выбранную отметку или удаляет элемент рисунка; `Esc` отменяет
  выбор инструмента размещения. Эти сочетания не перехватываются в полях ввода.
- `Shift` + щелчок выделяет несколько элементов. Доступны группировка, выравнивание
  по левому/верхнему краю и совместное перемещение с сохранением расстояний.
- `Ctrl+C` / `Ctrl+V` и «Дублировать» копируют элементы рисунка. `Ctrl+D` дублирует
  выделение. Копии кабинетов получают новые идентификаторы и пустые номера.
  Учётные рабочие места и оборудование не дублируются: «Стол» создаёт копируемый
  элемент планировки, а реальный объект добавляется из списка.
- Привязка к стенам подводит точку к ближайшему отрезку на расстоянии до 0,35 м.
  Переключатель «Заблокировать перемещение» защищает готовый контур или отметку
  от перетаскивания, изменения размеров и удаления. Разблокировка доступна в свойствах.

В карточках устройства, рабочего места и поштучного оборудования есть кнопка
«На карте» или «Разместить на карте». Она открывает нужный этаж и выделяет отметку
либо переводит редактор в режим выбора места.

Удаление отметки не удаляет оборудование или рабочее место. Удалённые и архивные
объекты остаются на сохранённом плане серыми отметками; их можно снять. Новый
архивный или количественный объект размещать нельзя. Удаление этажа удаляет
его рисунок, отметки и подложку, сохраняя все учётные карточки. Здание удаляется
после удаления его этажей.

## Дополнительные инструменты редактора

- Умные направляющие подводят края и центры выделения к другим объектам в пределах
  6 пикселей и показывают линию привязки. `Alt` временно отключает привязку при движении.
- «Опорный объект» задаёт неподвижную основу выравнивания по краям или центрам.
  Он выделяется фиолетовым. Можно также сделать одинаковую ширину или высоту
  выбранных комнат и столов по размерам опорного объекта.
- «Равные интервалы» распределяет минимум три объекта по горизонтали или вертикали.
  Пустое поле промежутка сохраняет крайние положения; числовое значение задаёт
  расстояние между краями в метрах. Блокировки и границы плана не нарушаются.
  Не выделяйте одновременно комнату и её отметки для распределения.
- В режиме «Выбор» удерживайте левую кнопку мыши и протяните рамку по свободному
  месту или внутри невыделенного кабинета. Отдельная кнопка для этого не нужна.
  Выбираются целиком попавшие внутрь элементы; `Shift` добавляет их к выделению.
  Щелчок выбирает кабинет, после чего его можно перетащить вместе с отметками.
  Перетаскивание остальных объектов, маркеров размера и средней кнопки мыши
  сохраняет обычное поведение. В режиме просмотра свободное место перемещает вид.
- Стрелки перемещают выделение на 0,1 м, `Shift` со стрелкой — на 1 м.
- «Измерить расстояние»: протяните линию. Её длина показывается в метрах.
  «Линейки и отступы до стен» включает линейки и расстояния
  от выбранного объекта до ближайших горизонтальных и вертикальных стен.
  Это размеры схемы; точность зависит от указанных габаритов плана.
- «Шаблоны расстановки» сохраняет выбранные элементы рисунка в браузере отдельно
  для пользователя. При вставке создаются новые идентификаторы и очищаются номера
  кабинетов. Оборудование и сетевые узлы не копируются. Очистка данных браузера
  удаляет шаблоны; они не переносятся на другие устройства.

## Карта сети

Включите «Карта сети» над планом. В режиме редактирования доступны коммутаторы,
маршрутизаторы, точки Wi-Fi, патч-панели, розетки, компьютеры, принтеры, серверы
и произвольные узлы. Для каждого задаются имя, порты, IP/MAC, сетевое имя,
группа (например VLAN) и примечание. Тип порта: Ethernet, оптика, Wi-Fi или логический.

Узел можно привязать к существующей карточке устройства или поштучного оборудования.
IP/MAC берутся из текущей карточки. Включённое следование отметке использует
положение оборудования или его рабочего места на этом этаже; перетаскивание
узла отключает следование. Перемещение карточки на другой этаж помечается
предупреждением и требует проверки схемы. Карточка не изменяется при правке узла.
Одной карточке соответствует максимум один сетевой узел во всех зданиях.

Нажмите «Соединить узлы», затем два узла на плане и выберите порты. Кнопка
«Выбрать узлы и порты» позволяет выбрать узлы с других этажей. Кабель имеет
номер, тип, состояние по учёту, группу и примечание. Для медного и оптического
кабеля порт должен соответствовать среде и может быть занят одним установленным
или запланированным соединением. Отключённое соединение освобождает порт.
Проверка работает по всем этажам, включая одновременное редактирование.

Двойной щелчок по кабелю добавляет изгиб; перетаскивание точки меняет маршрут,
двойной щелчок по точке удаляет её. Точные координаты доступны в свойствах кабеля.
«Автомаршрут» возвращает простую ломаную. Межэтажный кабель обозначается переходом
↗; переход можно переместить, а из свойств открыть другой этаж. Кабель редактируется
на плане, где создан. Перед удалением узла, порта или этажа нужно убрать соединения,
которые ссылаются на него с других планов.

«Показать цепочку» ищет путь по установленным соединениям до ближайшего
маршрутизатора или выбранного конечного узла. Коммутатор, маршрутизатор и точка
доступа связывают свои порты. Пассивные патч-панели и розетки пропускают путь
только через явно заданные пары портов (генератор «Передний + задний» создаёт пары).
Компьютеры, принтеры и серверы не соединяют свои порты транзитом.
Подсветка описывает учётную топологию; опрос оборудования, проверка доступности
и определение реального сетевого маршрута здесь не выполняются.

Сеть можно показать целиком, только для выбранного узла или цепочки, отфильтровать
по группе, скрыть подписи. Сетевые узлы включены в общий поиск по имени, IP и группе.
Изменения сети входят в отмену/повтор, локальный черновик и историю плана.
Восстановление старой версии загружает сеть для проверки; конфликтующие с другими
этажами порты и удаление используемых узлов будут отклонены при сохранении.

## Публикация плана

Изменения публикуются кнопкой «Сохранить план». Перед сменой этажа и переходом
по ссылкам редактор предлагает отбросить несохранённые изменения; обновление
страницы вызывает предупреждение браузера. Несохранённый документ и загруженная
подложка автоматически записываются в IndexedDB на этом устройстве после короткой
паузы в редактировании. Состояние записи показано над картой. Черновики разделены
по пользователю и этажу; при повторном открытии предлагается восстановить или удалить
черновик. Успешная публикация и явный отказ от изменений очищают его.
Если серверный план уже изменился, старый черновик не сможет перезаписать новую
версию. В другом браузере или после очистки данных браузера локального черновика нет.
Отмена действий относится к рисунку и отметкам; выбор нового файла подложки
отменяется кнопкой «Убрать подложку».

Каждая публикация создаёт неизменяемую версию с датой, автором и необязательным
названием. Кнопка «История планов» открывает сохранённые варианты. «Загрузить
в редактор» возвращает рисунок, отметки и подложку для проверки; сохранение
создаёт новую версию и не удаляет более поздние. Недоступные отметки пропускаются
после подтверждения; возврат отметки с другого этажа требует подтверждения переноса
и актуальной версии исходного этажа. Сведения о людях и оборудовании всегда берутся
из текущих карточек, а не из старого снимка.

Предыдущие подложки сохраняются вместе с версиями, даже после замены или снятия
текущей подложки. При удалении этажа удаляются его версии и больше не используемые
подложки. На старых установках история начинается с состояния перед первым новым
сохранением; более ранние варианты восстановить нельзя.

Каждое сохранение проверяет версию. Если другой пользователь уже сохранил план,
изменения остаются в редакторе и появляется предупреждение. Кнопка «Загрузить
версию сервера» после подтверждения заменяет локальный рисунок сохранённой версией.

Таблицы `map_buildings`, `map_floors`, `map_markers`, `map_floor_versions` создаются
при запуске API. К существующим отметкам добавляются кабинет, блокировка и группа;
координаты и учётные карточки сохраняются. Подложки хранятся в
`PHOTO_DIRECTORY/_map_backgrounds` с безопасными сгенерированными именами.
Для резервного копирования нужны БД и весь каталог фотографий, включая подложки.
Сетевой документ хранится в `map_floors.network_json`; `map_network_state`
содержит общую версию топологии для защиты портов между этажами.
При первом запуске новый столбец добавляется с пустой сетью без изменения карточек,
координат или прежних снимков истории.

После переноса исходников на сервер пересоберите оба сервиса:

```bash
sudo docker compose up -d --build api frontend
```

Пересборка Nginx нужна в том числе для лимита загрузки подложки: 13 МБ на запрос
с изображением и описанием плана.

## API и проверки

Все маршруты `/api/maps` требуют обычную авторизацию Bearer JWT:

| Маршрут | Назначение |
|---|---|
| `GET/POST /api/maps/buildings` | Список и создание зданий |
| `PUT/DELETE /api/maps/buildings/{id}` | Изменение или удаление здания |
| `POST /api/maps/buildings/{id}/floors` | Создание плана |
| `GET /api/maps/floors/{id}` | Геометрия, отметки, актуальные данные карточек |
| `PUT /api/maps/floors/{id}` | Атомарное сохранение плана |
| `DELETE /api/maps/floors/{id}?revision=N` | Удаление с проверкой версии |
| `GET /api/maps/floors/{id}/background` | Авторизованная загрузка подложки |
| `GET /api/maps/floors/{id}/versions?page=1&page_size=20` | История публикаций |
| `GET /api/maps/floors/{id}/versions/{revision}` | Документ сохранённой версии |
| `GET /api/maps/floors/{id}/versions/{revision}/background` | Подложка версии |
| `GET /api/maps/catalog` | Объекты и их текущие отметки |
| `GET /api/maps/network` | Узлы и соединения всех этажей, общая версия сети |
| `GET /api/maps/locate/{type}/{id}` | Поиск карточки или сотрудника на карте |

Сохранение использует `multipart/form-data`: поле `document` содержит JSON
`FloorSave`, необязательное поле `file` — новое изображение. Текущий `revision`
обязателен. Геометрия ограничена 2000 элементами, отметки — 1000 на план,
размеры плана — 2–500 м по каждой оси. Для подтверждённого переноса отметки
передаются `from_floor_id` и `from_revision` исходного этажа.
Поле `network` содержит массивы `nodes` и `links`; для изменения сети передаётся
`network_revision` из загруженного плана. Если `network` отсутствует у старого
клиента, существующая сеть сохраняется. Лимиты: 1000 узлов, 2000 соединений,
256 портов на узел, 100 изгибов на кабель.

Проверки: `python -m unittest discover -s tests -p "test_map*.py"` из `backend`,
`node --test tests/*.test.mjs` и `npm run build` из `frontend`.
