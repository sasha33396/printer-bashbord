# Интерактивная карта помещений

Раздел **Карта помещений** содержит здания и планы этажей. План можно начертить
с нуля или использовать готовое изображение как подложку. Рабочие места,
печатающая техника и поштучное оборудование размещаются отметками, связанными
с существующими карточками.

## Создание плана

1. Нажмите «Добавить здание», задайте название, адрес и при необходимости филиал.
2. В блоке «Этажи / планы» нажмите «+». Укажите название и размеры плана в метрах.
   Один план может представлять этаж, отдельное помещение или схему всего здания.
3. Нажмите «Редактировать план».
4. Выберите «Комната» и протяните прямоугольник. Подпись, цвет и размеры меняются
   в панели «На плане». Сложные контуры можно составить из отдельных стен.
5. Инструментами «Стена» и «Дверь» протяните линии; «Подпись» добавляет текст
   по щелчку на плане. Дверь отображается проёмом с направлением открывания.
6. Нажмите «Сохранить план». Геометрия, отметки и новая подложка сохраняются вместе.

Размеры плана меняются через «Параметры плана». Уменьшение, при котором элементы
оказались бы за границами, блокируется. Редактор использует схематические размеры
в метрах; задание ширины и длины изображения не измеряет помещения автоматически.

## Подложка из изображения

В режиме редактирования нажмите «Загрузить подложку». Поддерживаются JPEG, PNG
и WebP размером до 10 МБ. Подложка занимает прямоугольник плана. Задайте размеры
по реальному зданию; кнопка «Пропорции изображения» подбирает длину по соотношению
сторон картинки при сохранении заданной ширины.

Ползунок регулирует видимость подложки. «Убрать подложку» удаляет её при следующем
сохранении. До сохранения выбор изображения и изменения видны только в редакторе.
PDF нужно предварительно преобразовать в изображение.

## Размещение сотрудников и оборудования

Слева доступны поиск по сотруднику, названию, категории и инвентарному номеру,
а также фильтр типа объекта. Поиск рабочего места учитывает названия и номера
закреплённого за ним оборудования.

В режиме редактирования выберите объект в списке и нажмите на его место на плане.
Для перемещения включите «Выбор» и перетащите отметку. Точные координаты и поворот
задаются в панели «На плане».

У рабочего места показываются текущий сотрудник и закреплённое оборудование
со ссылками на карточки. Изменения сотрудника и состава оборудования берутся
из учётных данных при открытии или обновлении плана.

У каждой карточки может быть одна собственная отметка во всех зданиях. Если она
уже находится на другом этаже, редактор просит подтвердить перенос. При сохранении
отметка исчезает с прежнего этажа, а версии обоих планов обновляются. Параллельно
открытый старый план не сможет вернуть её обратно устаревшим сохранением.

Оборудование рабочего места можно найти через отметку этого рабочего места без
отдельной отметки каждого монитора или компьютера. Установленный картридж можно
найти через отметку принтера. При необходимости отдельная отметка оборудования
имеет приоритет при поиске.

Здание можно привязать к филиалу. На его планах размещаются объекты этого филиала
и объекты без указанного филиала. Размещение на карте не заменяет складские передачи
или перемещение рабочего места между филиалами. Если филиал объекта впоследствии
изменится, старая отметка помечается предупреждением и требует переноса или снятия.

## Просмотр и управление

- Колесо мыши и кнопки «+»/«−» меняют масштаб; «Весь план» возвращает общий вид.
- Средняя кнопка мыши или инструмент «Перемещение вида» двигают видимую область.
- Щелчок выбирает элемент, двойной щелчок по отметке в режиме просмотра открывает
  карточку. На телефоне можно выбрать отметку и нажать «Открыть карточку».
- Синий маркер в углу комнаты меняет её размер; маркер конца стены или двери
  меняет конечную точку. Для этого используйте инструмент «Выбор».
- Сетка может отображаться независимо от привязки. Шаг привязки — 0,5 м, 1 м
  или без привязки.
- `Ctrl+Z` отменяет, `Ctrl+Shift+Z` повторяет изменения рисунка и отметок.
- `Delete` снимает выбранную отметку или удаляет элемент рисунка; `Esc` отменяет
  выбор инструмента размещения. Эти сочетания не перехватываются в полях ввода.

В карточках устройства, рабочего места и поштучного оборудования есть кнопка
«На карте» или «Разместить на карте». Она открывает нужный этаж и выделяет отметку
либо переводит редактор в режим выбора места.

Удаление отметки не удаляет оборудование или рабочее место. Удалённые и архивные
объекты остаются на сохранённом плане серыми отметками; их можно снять. Новый
архивный или количественный объект размещать нельзя. Удаление этажа удаляет
его рисунок, отметки и подложку, сохраняя все учётные карточки. Здание удаляется
после удаления его этажей.

## Сохранение и обновление сервера

Изменения сохраняются кнопкой «Сохранить план». Перед сменой этажа и переходом
по ссылкам редактор предлагает отбросить несохранённые изменения; обновление
страницы вызывает предупреждение браузера. Автоматического сохранения черновиков
между сессиями нет. Отмена действий относится к рисунку и отметкам; выбор нового
файла подложки отменяется кнопкой «Убрать подложку».

Каждое сохранение проверяет версию. Если другой пользователь уже сохранил план,
изменения остаются в редакторе и появляется предупреждение. Кнопка «Загрузить
версию сервера» после подтверждения заменяет локальный рисунок сохранённой версией.

Новые таблицы `map_buildings`, `map_floors` и `map_markers` создаются при запуске API
без изменения существующих карточек. Подложки хранятся в
`PHOTO_DIRECTORY/_map_backgrounds` с безопасными сгенерированными именами.
Для резервного копирования нужны БД и весь каталог фотографий, включая подложки.

После переноса исходников на сервер пересоберите оба сервиса:

```bash
sudo docker compose up -d --build api frontend
```

Пересборка Nginx нужна в том числе для лимита загрузки подложки: 13 МБ на запрос
с изображением и описанием плана.

## API и проверки

Все маршруты `/api/maps` требуют обычную авторизацию Bearer JWT:

| Маршрут | Назначение |
|---|---|
| `GET/POST /api/maps/buildings` | Список и создание зданий |
| `PUT/DELETE /api/maps/buildings/{id}` | Изменение или удаление здания |
| `POST /api/maps/buildings/{id}/floors` | Создание плана |
| `GET /api/maps/floors/{id}` | Геометрия, отметки, актуальные данные карточек |
| `PUT /api/maps/floors/{id}` | Атомарное сохранение плана |
| `DELETE /api/maps/floors/{id}?revision=N` | Удаление с проверкой версии |
| `GET /api/maps/floors/{id}/background` | Авторизованная загрузка подложки |
| `GET /api/maps/catalog` | Объекты и их текущие отметки |
| `GET /api/maps/locate/{type}/{id}` | Поиск карточки или сотрудника на карте |

Сохранение использует `multipart/form-data`: поле `document` содержит JSON
`FloorSave`, необязательное поле `file` — новое изображение. Текущий `revision`
обязателен. Геометрия ограничена 2000 элементами, отметки — 1000 на план,
размеры плана — 2–500 м по каждой оси. Для подтверждённого переноса отметки
передаются `from_floor_id` и `from_revision` исходного этажа.

Проверки: `python -m unittest discover -s tests -p test_maps.py` из `backend`,
`node --test tests/*.test.mjs` и `npm run build` из `frontend`.
