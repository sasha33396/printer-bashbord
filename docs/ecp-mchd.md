# Учет ЭЦП и МЧД

Новый пункт слева открывает две вкладки: «ЭЦП» и «МЧД». Реестр заполняется вручную или импортом Excel.
Каждая вкладка содержит все 15 согласованных полей, поиск, фильтры в столбцах,
карточку с полными значениями, создание, редактирование, архив и восстановление.
Длинные значения в таблице сокращаются с подсказкой; идентификаторы можно скопировать в карточке.

Обязательные поля ЭЦП: название компании, ФИО, действителен с, действителен по.
Обязательные поля МЧД: номер доверенности, наименование доверителя, ФИО лица представителя,
даты начала и окончания. Остальные поля можно заполнить позднее или очистить.
ИНН, СНИЛС, номера, отпечаток и идентификаторы хранятся как текст с сохранением ведущих нулей.
Тип, вид подписи, применение, состояние ЭП и статус МЧД ЭДО вводятся вручную.
Разрешения МЧД допускают несколько строк. Номер доверенности не генерируется приложением.

Дата окончания включается в срок действия; она не может предшествовать дате начала.
Отметка «Срок» вычисляется при чтении записи по календарной дате Саратова (UTC+04:00):

- «Срок не начался»: дата начала позже сегодняшней.
- «Срок действует»: срок начался, до окончания осталось более 30 дней.
- «Скоро истекает»: от 0 до 30 дней до окончания включительно.
- «Срок истёк»: дата окончания прошла.

Расчёт касается только дат, не заменяет введённое состояние ЭП или статус МЧД ЭДО.
Дата отзыва, создания, изменения и архива сохраняется в UTC, отображается в местном времени браузера.
API принимает дату отзыва с часовым поясом; даты начала и окончания передаются как `YYYY-MM-DD`.
Для актуализации отметок на давно открытой странице есть кнопка «Обновить».

Архивирование сохраняет все сведения. Архив виден отдельным переключателем каждой вкладки;
архивную карточку можно открыть и восстановить. Редактировать её можно после восстановления.
Доступ к разделу и API осуществляется через существующий вход в приложение.

## Импорт одного XLSX с двумя листами

В разделе нажать «Импорт XLSX», выбрать файл, затем «Проверить файл».
Приложение покажет каждую строку и результат: новая запись, точный повтор, ошибка или несовпадение.
Строку можно раскрыть и проверить все значения. Если проверка прошла, нажать «Импортировать».
Оба листа добавляются одной операцией: при ошибках или несовпадениях ничего не записывается.
После исправлений выбрать исправленный файл и проверить его заново.

- Названия листов: `ЭЦП` и `МЧД`; регистр и пробелы по краям не важны. Дополнительные листы игнорируются.
- Заголовки совпадают с названиями полей в таблицах приложения. Порядок столбцов произвольный;
  переносы строк и лишние пробелы в заголовках допускаются. Вариант `Действителен c` с латинской `c` поддерживается.
  Заголовок ищется в первых 20 строках, поэтому над таблицей может быть название отчёта.
- Все обязательные столбцы должны присутствовать. Недостающие необязательные столбцы остаются пустыми,
  приложение предупреждает об этом. Пустые строки и дополнительные столбцы игнорируются.
- Даты: обычные даты Excel, `ДД.ММ.ГГГГ` или ISO (`YYYY-MM-DD`). Дата и время отзыва также принимает
  `ДД.ММ.ГГГГ ЧЧ:ММ:СС` или ISO с часовым поясом. Время Excel без пояса считается временем Саратова (UTC+04:00).
- ИНН, СНИЛС, номера и идентификаторы желательно хранить **текстом**. Текстовые ведущие нули сохраняются;
  числовые ячейки с форматом `0000000000` сохраняют отображаемые нули. Уже потерянные Excel цифры восстановить
  нельзя: числовые идентификаторы длиннее 15 цифр отклоняются. Формулы нужно заменить результатами через «Вставить значения».
- До 10 МБ, до 10 000 строк данных на листе. Лишние пустые строки с форматированием за пределами таблицы следует удалить.

Существующие записи **не перезаписываются**. Повтор определяется по отпечатку ЭЦП,
серийному номеру вместе с компанией (ИНН при наличии), идентификаторам МЧД ФНС/ЭДО;
для МЧД также по номеру, доверителю и периоду действия. При совпадении идентификатора и различиях в полях
показывается несовпадение со ссылкой на существующую карточку — нужно сверить источник и запись вручную.
Без отпечатка и серийного номера повтор ЭЦП определяется только по точному совпадению всех полей.
Точные повторы внутри файла добавляются один раз. Архивные записи не восстанавливаются автоматически.
Повторная отправка того же файла не создаёт дубликаты; перед записью приложение снова проверяет актуальные записи БД.

## API

Базовые пути:

- `/api/digital-documents/signatures` — ЭЦП.
- `/api/digital-documents/powers-of-attorney` — МЧД.

Для каждого пути доступны:

| Метод | Путь | Действие |
|---|---|---|
| GET | базовый путь | Актуальные записи |
| GET | базовый путь `?archived=true` | Архив |
| POST | базовый путь | Создать |
| GET | `/{id}` | Карточка, включая архивную |
| PUT | `/{id}` | Обновить, допускаются отдельные поля |
| DELETE | `/{id}` | Переместить в архив |
| POST | `/{id}/restore` | Восстановить |

Контракт полей доступен в `/docs`. Ответ также содержит `id`, `created_at`, `updated_at`,
`is_archived`, `archived_at`, `term_status`, `days_left`.
Дата окончания проверяется и при частичном обновлении. Служебные поля нельзя задавать через создание или редактирование.

Импорт: `POST /api/digital-documents/import-xlsx` с multipart-полем `file`.
Без параметров — проверка, с `?apply=true` — повторная проверка и запись обеих таблиц одной транзакцией.
Ответ содержит `mode`, `applied`, `can_apply`, `totals`, `rows` (лист, номер строки, результат, данные), `warnings`.
Ошибки отдельных строк возвращаются в отчёте с `can_apply=false`; нечитаемый файл или неподходящие заголовки — HTTP 422.
Авторизация обязательна, как и для остальных операций раздела.

## Обновление сервера

Ветка: `feature/ecp-mchd`, основана на `feature/ocs-ad-import` и включает его изменения.
Перед обновлением сохранить актуальную резервную копию БД. Новые таблицы
`electronic_signatures` и `machine_readable_powers_of_attorney` создаются при запуске API.
Существующее оборудование, номера, сотрудники и фотографии сохраняются.

```bash
cd /opt/printer-bashbord
git fetch origin
git switch feature/ecp-mchd
git pull --ff-only
sudo docker compose up -d --build api frontend
sudo docker compose logs --tail 30 api
```

После запуска обновить браузер через Ctrl+F5.
