# Поштучный учёт картриджей

Раздел **Картриджи** доступен в меню и из категории «Картриджи» на складе.
Каждый физический картридж — отдельная складская карточка с обязательным номером
наклейки `1-00001`. Номера уникальны среди всего оборудования, включая архив.
Этикетка печатается кнопкой «Этикетка» в открытой карточке, общий сканер открывает карточку картриджа.
Номера не генерируются автоматически.

В каждой строке списка справа расположены **Открыть**, карандаш для редактирования
и корзина для удаления с подтверждением. В редакторе можно изменить наименование,
артикул, производителя, модель, серийный номер, описание совместимости и примечание.
Номер наклейки закреплён за историей; состояние и местонахождение меняются
через операции оборота. Списанные карточки доступны для просмотра и удаления,
редактирование для них отключено. Кнопка «Редактировать» также есть в открытой карточке.

## Начало работы

1. Откройте «Картриджи → Добавить / разобрать остаток».
2. Для нового поступления оставьте источник пустым. Для уже учтённых картриджей
   выберите существующую складскую позицию.
3. Введите модель, номера наклеек (до 100 за раз), филиал, при необходимости отдел,
   дату и фактическое состояние: запасной, пустой или неисправный.
4. Для количественной позиции остаток уменьшится ровно на число созданных карточек.
   Единица с уже существующим номером подключается к учёту оборота без создания
   второй карточки. Если номер у неё пока отсутствует, сначала заполните его
   в обычной складской карточке. Картридж, закреплённый за рабочим местом старым
   способом, сначала нужно снять с рабочего места.

Если у старой позиции не задан филиал, сначала заполните её филиал и отдел
на складе: при преобразовании начальная локация сохраняется.

Старые записи не преобразуются автоматически: по количеству нельзя определить
номера наклеек и фактические состояния. Повторно регистрировать тот же номер
нельзя. Операцию уменьшения старого остатка после преобразования нельзя удалить
как обычную складскую выдачу.

## Операции

- **Передача** — склад, конкретный отдел или сотрудник. Для сотрудника выбираются
  его филиал и отдел. Местонахождение меняется у выбранных картриджей; второй
  экземпляр или расход складского количества при передаче не создаётся.
- **Установка / замена** — выберите принтер и место установки. У монохромного
  принтера это «Основной», у цветного можно использовать названия цветов.
  Если место занято, форма покажет снимаемый картридж. Снятие старого и установка
  нового сохраняются одной транзакцией с общим идентификатором операции.
  Старый картридж становится пустым у прежнего получателя. Устанавливаемый
  числится за выбранным сотрудником или отделом по местонахождению принтера.
- **Снятие** — установленный картридж становится пустым и передаётся указанному
  получателю. Можно снять картридж без немедленной замены.
- **Отправка на заправку** — выберите пустые картриджи, подрядчика и дату.
- **Возврат с заправки** — выберите фактически вернувшиеся номера и получателя.
  Частичный возврат оформляется выбором части партии. Неисправные возвращаются
  отдельной операцией с соответствующим результатом; успешная заправка увеличивает
  счётчик заправок, неисправный возврат — нет.
- **Неисправность / списание** — доступны для снятых картриджей вне заправки.
  Списанные автоматически переходят в архив оборудования, их история остаётся
  доступна в разделе картриджей. Отмены списания нет.

Операция не может предшествовать последней операции с тем же картриджем или
иметь будущую дату. Пакет сохраняется целиком: ошибка одного номера отменяет
изменения остальных. Конкурирующие изменения проверяются версией записи;
одно место принтера не может одновременно занимать два картриджа.

## Даты, длительность и сроки заправки

В списке и карточке показаны дата начала текущего состояния и число календарных
дней в нём, начало текущего местонахождения и дата последней передачи.
Передача не сбрасывает длительность состояния: запасной картридж остаётся
запасным независимо от смены получателя. Установка и снятие меняют состояние
и местонахождение. Даты восстанавливаются из существующего журнала операций;
если достоверной записи нет, выводится «Дата неизвестна».

При отправке на заправку можно указать **ожидаемую дату возврата**. Она не может
предшествовать дате отправки. Срок необязателен: старые записи остаются без срока.
Находящимся на заправке картриджам срок можно задать, изменить или убрать кнопкой
**Срок возврата**; это сохраняется отдельным событием и не сбрасывает длительность
заправки. Срок не может быть раньше последней отправки. При фактическом возврате
текущий срок очищается, исходный срок остаётся в истории.

Просрочка начинается **на следующий день** после срока возврата. Календарный день
определяется сервером в UTC+04:00. В списке видны срок и количество дней просрочки,
а над списком — предупреждение с кнопкой перехода к просроченным.
Фильтр «Контроль сроков» содержит:

- просроченный возврат с заправки;
- заправку без указанного срока;
- пустые картриджи, ожидающие отправки;
- установленные дольше заданного количества дней (порог вводится рядом).

Изменение срока не является подтверждением фактического возврата. Для возврата
используйте обычную операцию **Возврат с заправки**.

## Справочник совместимости

Кнопка **Совместимость моделей** открывает справочник связей
«наименование картриджа → производитель и модель принтера».
Настройка действует для всех экземпляров с этим наименованием. Пробелы и регистр
при сопоставлении нормализуются. Можно выбрать существующее наименование или
ввести новое, добавить несколько моделей принтеров и удалить ненужные связи.

При установке сначала выбирается принтер. В списке картриджей остаются запасные,
совместимые с его моделью. Для старых записей есть флажок
**Показывать модели без настроенной совместимости**: они помечаются предупреждением
и допускаются к установке после проверки оператором. Выключите флажок, чтобы
видеть только подтверждённые справочником варианты. Известное несовпадение
отклоняется также сервером, независимо от интерфейса.

Прежнее поле **Описание совместимости** сохраняется для справки. Его текст
не преобразуется автоматически в связи. Пустой список связей означает
«совместимость неизвестна», а не запрет установки.

## Ресурс между заменами

В форме установки / замены есть необязательное поле счётчика принтера.
Последнее сохранённое показание можно явно подставить кнопкой; рядом показана
дата его получения, если она известна. Автоматического сетевого опроса в форме нет.
При замене одно введённое показание одновременно завершает цикл снимаемого
картриджа и начинает цикл устанавливаемого. Место / цвет при единственном
установленном картридже подставляется из текущей установки.

При отдельном снятии для каждого выбранного картриджа показание вводится отдельно.
Ресурс считается так:

```text
Напечатано за цикл = счётчик при снятии − счётчик при установке
```

Счётчик — целое неотрицательное число. Уменьшение относительно установки
отклоняет операцию целиком: старый картридж остаётся на месте, новый не устанавливается.
Если одно из показаний пропущено, ресурс цикла **неизвестен**. Нулевой ресурс
сохраняется как ноль. Показание из карточки принтера не подменяет пропущенное
значение автоматически; при сбросе счётчика требуется оставить ресурс неизвестным.

В карточке показаны счётчик текущей установки, ресурс последнего завершённого цикла,
сумма страниц только по измеренным циклам и их количество. Во вкладке
**Ресурс между заменами** — даты установки/снятия, принтер, слот, оба показания
и число страниц. История сохраняется и после заправки, переноса или списания.

## Остатки и история

На вкладке «Остатки по получателям» доступны два вида:

- По получателям: склад, отдел, каждый сотрудник и каждый подрядчик отдельно.
- Итого по отделам: включая картриджи сотрудников этого отдела и картриджи,
  отправленные из него на заправку. Пока картридж у подрядчика, сохраняется
  филиал и отдел отправления; при возврате указывается новое местонахождение.

**Запасные** — готовые к использованию картриджи в состоянии «Запасной». Установленные,
пустые, неисправные и находящиеся на заправке показаны отдельными числами.
Списанные в остатки не входят. Поиск и фильтры списка применяются и к сводке.

Карточка картриджа показывает даты последней установки, снятия, отправки,
возврата и число успешных заправок. В истории сохраняются дата, получатель,
состояния до и после, принтер, подрядчик, пользователь и примечание. Операции
также отображаются в общем журнале движений с категорией «Картридж».
В карточке принтера есть текущие картриджи по местам, последняя установка,
последние операции и переход к замене.

История расходников, ранее введённая в карточках принтеров, остаётся отдельной:
она не содержит номеров конкретных картриджей и автоматически не преобразуется.

В карточке по умолчанию открывается **Лента событий**: каждый этап оборота
показан отдельно с датой, местом, принтером, подрядчиком, исполнителем,
примечанием и показаниями, если они были введены. Табличная история остаётся
отдельной вкладкой; циклы в один день упорядочиваются по порядку регистрации.

## Удаление карточки

Кнопка **Удалить** находится в правом закреплённом столбце списка,
**Удалить карточку** — в самой карточке. Диалог показывает номер и наименование;
нужно подтвердить удаление или нажать «Отмена».

Удаление убирает карточку из списка картриджей, сводки остатков и выбора для
операций. Если картридж установлен, его слот принтера освобождается; текущие
привязки к сотруднику и подрядчику снимаются. Это удаление записи из учёта,
а не операция снятия или списания: выдуманный ресурс при этом не создаётся.

История сохраняется вместе с событием удаления, исполнителем и датой.
Складская карточка и фотографии остаются в архиве с пометкой «Удалено из учёта».
Номер наклейки остаётся занят, повторное создание с этим номером блокируется.
Сканирование номера открывает архивную складскую карточку. Восстановление
удалённого картриджа как обычного складского оборудования запрещено.

При подтверждении проверяется версия записи: если другой пользователь успел
изменить карточку, удаление отклоняется, нужно обновить список. Признак удаления
сохраняется при перезапуске. Старые карточки после обновления остаются доступны.

## Обновление и хранение

После пересборки API и интерфейса новые таблицы `cartridges` и
`cartridge_operations` создаются при запуске. В `stock_movements` добавляется
признак защищённой операции преобразования `cartridge_conversion`. Миграция
повторно применима, существующие остатки не меняет.

Для контроля сроков и ресурса добавляются необязательные поля
`cartridges.expected_return_date`, `cartridges.installation_page_counter`,
`cartridges.is_deleted` (по умолчанию `false`),
`cartridge_operations.page_counter`, `cartridge_operations.pages_printed`,
`cartridge_operations.expected_return_date` и справочник `cartridge_compatibility`.
Старые операции, версии карточек и назначения сохраняются. Показания и сроки
у старых записей автоматически не придумываются. Обновлять нужно API и интерфейс.

Обычные складские операции и назначения на рабочие места не могут менять оборот
зарегистрированных картриджей. Описание и фотографии редактируются в карточке
оборудования; номер наклейки после регистрации закреплён за картриджем.
Нельзя удалить сотрудника или отдел с картриджами, а также удалить или перенести
принтер с установленными картриджами до их снятия.

Для полного резервного копирования сохраняйте БД, фотографии и PDF-счета.
ZIP-экспорт оборудования содержит обычные карточки и фотографии, но не является
резервной копией истории оборота картриджей. Перезапись зарегистрированного
картриджа через импорт такого ZIP блокируется.

## API

Все маршруты требуют обычный Bearer JWT:

| Маршрут | Назначение |
|---|---|
| `GET /api/cartridges` | Карточки всех картриджей, включая списанные |
| `POST /api/cartridges` | Поступление или перевод старого остатка в поштучный учёт |
| `GET /api/cartridges/{item_id}` | Карточка |
| `DELETE /api/cartridges/{item_id}?version=N` | Удаление из учёта с проверкой версии, история и складской архив сохраняются |
| `POST /api/cartridges/actions` | Пакетная передача, снятие, заправка, возврат, неисправность или списание |
| `POST /api/cartridges/install` | Установка с атомарным снятием прежнего картриджа |
| `GET /api/cartridges/operations` | История, фильтры `item_id` и `device_id` |
| `GET /api/cartridges/compatibility` | Справочник совместимости моделей |
| `PUT /api/cartridges/compatibility` | Замена списка совместимых принтеров для одного наименования картриджа |

Контракт запросов доступен в `/docs`. Для установки `removed_item_id` должен
совпадать с текущим картриджем на выбранном месте (либо `null`, если оно свободно).
Это защищает от замены по устаревшим данным формы.

Дополнительные поля запросов:

- `POST /install`: `page_counter` — необязательное показание на момент установки/замены.
- `POST /actions`, операция `remove`: `page_counters` — объект
  `{"123": 10500, "124": 23000}` с показаниями только для выбранных снимаемых картриджей.
- `POST /actions`, `send_refill` / `refill_deadline`: `expected_return_date`
  (`YYYY-MM-DD` или `null`). `refill_deadline` применяется только к картриджам на заправке.
- `PUT /compatibility`: `{"cartridge_model": "TK-1170", "devices":
  [{"manufacturer": "Kyocera", "model": "ECOSYS M2040dn"}]}`.
  Пустой `devices` убирает связи; повторяющиеся пары отклоняются.

В ответе карточки доступны `state_since`, `state_days`, `location_since`,
`location_days`, `last_transferred_at`, `refill_overdue`, `overdue_days`,
`installation_page_counter`, `last_cycle_pages`, `measured_cycles`, `total_pages`
и `compatible_models`. Даты и ресурсы, для которых нет подтверждённых данных,
возвращаются как `null`.

Проверки: `python -m unittest discover -s tests -p test_cartridges.py` из `backend`,
`node --test tests/*.test.mjs` и `npm run build` из `frontend`.
